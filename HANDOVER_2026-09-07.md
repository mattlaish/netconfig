## Current product baseline

NetConfig is a standard-library-first Python 3.12+ network configuration and security operations
console reconstructed from an RPM payload. Application code lives under `opt/netconfig/`; RPM and
service integration lives under `packaging/`, `etc/`, and `usr/`.

Implemented capabilities relevant to the current baseline include:

- inventory, encrypted credential vault, configuration archive/diff, approvals and compliance;
- SSH/OpenSSH CLI transport, SNMP polling, MIB support, NetFlow/application monitoring;
- web console hardening: login throttling/audit, optional built-in TLS, security headers,
  structured JSON logs, `/healthz`, `/readyz`, `/metrics`;
- unattended vault bootstrap through systemd credential directory or root-only credential file;
- semantic remediation planning with vendor negation, fresh-state verification, rollback guards for
  Cisco IOS/ASA, Arista EOS and JunOS, and fail-closed behavior for unsupported platforms;
- bounded concurrent SNMP polling, SQLite WAL, storage/protocol abstraction boundaries;
- LLDP-MIB topology discovery, CDP CLI fallback, persisted edges, unmanaged-neighbour detection and
  a dependency-free SVG topology console;
- bounded UDP syslog-triggered immediate configuration collection;
- read-only scoped bearer-token API with hash-only token storage and audited reads;
- scheduled compliance + drift digest using the existing SMTP/O365 mailer;
- CI definition for Python 3.12, Ruff, mypy boundary checks, compileall, pytest, legacy self-test,
  OpenSSH fake device, Net-SNMP and PostgreSQL integration services;
- LF hygiene via `.gitattributes`, CI line-ending gate and repository-hygiene tests.

## Historical 2026-09-07 recommended development order

The canonical detailed roadmap is `ROADMAP.md`. The recommended order is:

### Slice A — Qualification and release gate closure (highest priority)

Before stacking more production-critical features, make the existing gates trustworthy in the target
Linux environment:

- run GitHub Actions or equivalent Python 3.12 environment with Ruff and mypy installed;
- execute the OpenSSH, Net-SNMP and PostgreSQL integration tier;
- build/inspect/install the RPM on AlmaLinux 10 and verify systemd hardening, `LoadCredential=`, TLS
  certificate/key permissions and service startup;
- validate semantic remediation/rollback on representative Cisco IOS/ASA, Arista EOS and JunOS labs;
- validate LLDP/CDP discovery and unmanaged-neighbour classification on representative devices;
- validate direct syslog and document a trusted-relay/NAT design before accepting relayed source identity;
- assign the next RPM release before the package is built.

### Slice B — VLAN-aware endpoint/topology correlation

Build the security value behind the topology feature:

- collect modern `ipNetToPhysicalTable` IPv4/IPv6 neighbour state;
- collect VLAN-aware Q-BRIDGE forwarding information;
- correlate IP -> MAC -> VLAN -> switch/port;
- enrich LLDP identity with chassis MAC, serial/system capabilities where available;
- distinguish managed infrastructure neighbours from unmanaged infrastructure/endpoints;
- expose downstream attachment/impact information through UI and read-only API;
- use canned SNMP walks for offline deterministic tests and then validate on real vendors.

### Slice C — SNMP traps and event correlation

- bounded trap receiver for linkDown/linkUp, coldStart/warmStart and authenticationFailure;
- target-device correlation and strict source validation;
- debounce/dedup and immediate targeted re-poll rather than broad fleet polling;
- correlate trap + syslog + polling evidence into one event timeline;
- dependency-aware suppression using the topology graph;
- never let untrusted relay metadata silently impersonate a managed device.

### Slice D — Alert lifecycle and audit/reporting closure

- alert acknowledgement/resolution lifecycle;
- maintenance windows and notification retry/backoff;
- dependency-aware downstream alert suppression;
- scheduled/exportable compliance, drift and topology audit reports;
- implement the previously designed bounded config-archive full-text search (read-only, audited,
  bounded regex/time/file budgets, secret-aware result handling).

### Slice E — Web-console structural hardening

- continue splitting the `web.py` monolith into route/response/template/static/security modules;
- remove inline event handlers/styles;
- move from transitional CSP to strict enforced nonce/script policy without `unsafe-inline`;
- preserve existing output escaping and regression coverage.

Session lifetime remains separately deferred unless the user explicitly selects it.

### Slice F — Core storage / HA scale

- migrate core state behind the storage boundary to PostgreSQL when multi-process/HA is actually required;
- introduce distributed job ownership/leases before multi-node pollers;
- test failover, duplicate-work prevention and retention/maintenance behavior;
- do not claim active-active operation from a thin storage adapter alone.

### Slice G — Structured network protocols

- implement capability-based NETCONF/RESTCONF/gNMI adapters where vendors support them;
- keep current CLI/OpenSSH support as the legacy fallback;
- prefer transactional structured protocols for configuration changes when proven by vendor/lab tests.
